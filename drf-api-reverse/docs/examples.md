# Examples

A complete example contract (`contract.yml`) and a script demonstrating
the programmatic API live in
[`examples/blog/`](https://github.com/MahmoudGShake/MahmoudPackages/tree/master/drf-api-reverse/examples/blog).
It defines three related resources - `Author`, `Article` (with a nested
`author` and an enum `status`), and `Comment` - across two top-level
paths, `/authors/` and `/articles/`, with `/articles/{id}/comments/` as
a nested read-only sub-resource.

## Scaffolding it

```bash
drf-api-reverse scaffold --schema examples/blog/contract.yml --output myapp/
```

```
Created myapp/serializers.py
Created myapp/views.py
Created myapp/urls.py
```

### `serializers.py`

```python
"""DRF serializers generated by drf-api-reverse from the OpenAPI contract.

Regions marked BEGIN/END DRF-API-REVERSE GENERATED are regenerated by
``drf-api-reverse scaffold`` - anything you add outside of them survives
a re-run untouched. See https://mahmoudgshake.github.io/MahmoudPackages/drf-api-reverse/architecture/
for how regeneration and drift detection work.
"""

from __future__ import annotations

from rest_framework import serializers


# === BEGIN DRF-API-REVERSE GENERATED: serializer:Author ===
class AuthorSerializer(serializers.Serializer):
    id = serializers.IntegerField(required=False)
    display_name = serializers.CharField()
    email = serializers.EmailField()
# === END DRF-API-REVERSE GENERATED: serializer:Author ===

# === BEGIN DRF-API-REVERSE GENERATED: serializer:Article ===
class ArticleSerializer(serializers.Serializer):
    id = serializers.IntegerField(required=False)
    title = serializers.CharField()
    status = serializers.ChoiceField(choices=['draft', 'published', 'archived'])
    author = AuthorSerializer(required=False)
    tags = serializers.ListField(child=serializers.CharField(), required=False)
    published_at = serializers.DateTimeField(required=False)
# === END DRF-API-REVERSE GENERATED: serializer:Article ===

# === BEGIN DRF-API-REVERSE GENERATED: serializer:Comment ===
class CommentSerializer(serializers.Serializer):
    id = serializers.IntegerField(required=False)
    body = serializers.CharField()
    author = AuthorSerializer(required=False)
# === END DRF-API-REVERSE GENERATED: serializer:Comment ===
```

Note `AuthorSerializer` is emitted *before* `ArticleSerializer` and
`CommentSerializer` even though `Article` appears first in the
contract's `components.schemas` - classes are emitted in dependency
order, not declaration order (see [Architecture](architecture.md)).

### `views.py`

```python
"""DRF viewsets generated by drf-api-reverse from the OpenAPI contract.
...
"""

from __future__ import annotations

from rest_framework import viewsets
from rest_framework.decorators import action

from .serializers import *  # noqa: F403


# === BEGIN DRF-API-REVERSE GENERATED: viewset:authors ===
class AuthorsViewSet(viewsets.ViewSet):
    serializer_class = AuthorSerializer

    def list(self, request, *args, **kwargs):
        raise NotImplementedError('Implement GET /authors/')

    def create(self, request, *args, **kwargs):
        raise NotImplementedError('Implement POST /authors/')

    def retrieve(self, request, *args, **kwargs):
        raise NotImplementedError('Implement GET /authors/{id}/')

    def update(self, request, *args, **kwargs):
        raise NotImplementedError('Implement PUT /authors/{id}/')

    def destroy(self, request, *args, **kwargs):
        raise NotImplementedError('Implement DELETE /authors/{id}/')
# === END DRF-API-REVERSE GENERATED: viewset:authors ===

# === BEGIN DRF-API-REVERSE GENERATED: viewset:articles ===
class ArticlesViewSet(viewsets.ViewSet):
    serializer_class = ArticleSerializer

    def list(self, request, *args, **kwargs):
        raise NotImplementedError('Implement GET /articles/')

    def create(self, request, *args, **kwargs):
        raise NotImplementedError('Implement POST /articles/')

    def retrieve(self, request, *args, **kwargs):
        raise NotImplementedError('Implement GET /articles/{id}/')

    def partial_update(self, request, *args, **kwargs):
        raise NotImplementedError('Implement PATCH /articles/{id}/')

    def destroy(self, request, *args, **kwargs):
        raise NotImplementedError('Implement DELETE /articles/{id}/')

    @action(detail=True, methods=['get'], url_path='comments')
    def list_article_comments(self, request, *args, **kwargs):
        raise NotImplementedError('Implement GET /articles/{id}/comments/')
# === END DRF-API-REVERSE GENERATED: viewset:articles ===
```

Note `/articles/{id}/comments/` did **not** get its own `ViewSet` - it
was folded into `ArticlesViewSet` as a `@action`, since it shares
`articles` as its top-level resource segment.

### `urls.py`

```python
"""URL routing generated by drf-api-reverse from the OpenAPI contract.
...
"""

from __future__ import annotations

from rest_framework.routers import DefaultRouter

from .views import *  # noqa: F403

router = DefaultRouter()


# === BEGIN DRF-API-REVERSE GENERATED: url:authors ===
router.register('authors', AuthorsViewSet, basename='authors')
# === END DRF-API-REVERSE GENERATED: url:authors ===

# === BEGIN DRF-API-REVERSE GENERATED: url:articles ===
router.register('articles', ArticlesViewSet, basename='articles')
# === END DRF-API-REVERSE GENERATED: url:articles ===


urlpatterns = router.urls
```

## Regenerating after adding your own code

Fill in `AuthorsViewSet.list`'s body with real logic, then re-run the
same command:

```bash
drf-api-reverse scaffold --schema examples/blog/contract.yml --output myapp/
```

Everything you added *outside* a generated method body (a new import,
a helper function, a whole extra `ViewSet` you wrote by hand)
survives untouched. Logic written *inside* a generated method's body
does not - see
[FAQ](faq.md#why-would-my-hand-written-viewset-logic-get-overwritten)
for exactly why, and the recommended pattern to avoid it.

## Programmatic usage

```python
# examples/blog/scaffold.py
import tempfile
from pathlib import Path

from drf_api_reverse import load_schema_file, scaffold

HERE = Path(__file__).parent

schema = load_schema_file(HERE / "contract.yml")

with tempfile.TemporaryDirectory() as tmp_dir:
    output_dir = Path(tmp_dir) / "myapp"
    for result in scaffold(schema, output_dir):
        verb = "Created" if result.created else "Updated"
        print(f"{verb} {output_dir / result.filename}")
```
